# Fonts

The fonts that ship with LiveLily, and their licenses:

| Font | Used for | License |
| --- | --- | --- |
| `DroidSansMono.ttf` | the editor | Apache License 2.0 (`DroidSansMono-LICENSE.txt`) |
| `LiberationSerif-Regular.ttf` (Liberation Fonts 2.1.5) | the names of instruments and the tempo in the score | SIL Open Font License 1.1 (`LiberationSerif-LICENSE.txt`) |

The notation of the score still uses Adobe's Sonata (`sonata.ttf`), which can't be redistributed and isn't in this repository:
to see the notes, put a copy of `sonata.ttf` in this folder. It is replaced by Bravura (SIL Open Font License) when the score is
drawn with JUCE (stage 4 of the migration plan).
